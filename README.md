# EduControl — Sistema de Gestión Académica

Aplicación web para administrar estudiantes, asignaturas y calificaciones mediante operaciones CRUD.

## Tecnologías
- HTML5
- CSS3
- JavaScript puro (Vanilla JavaScript)
- localStorage

## Cómo ejecutar
1. Descarga o clona este repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` con Live Server, o ábrelo directamente en el navegador.
4. Los datos se guardan en el almacenamiento local del navegador.

## Funcionalidades
- Dashboard con estadísticas.
- CRUD de estudiantes y búsqueda.
- CRUD de asignaturas.
- CRUD de calificaciones (rango de 0.0 a 5.0).
- Confirmación antes de eliminar.
- Validación de formularios.
- Persistencia mediante localStorage.
- Diseño adaptable.

## Prompts utilizados
1. **Planificación y arquitectura:** se solicitó definir la estructura, entidades, relaciones y etapas del proyecto sin generar todavía todo el código.
2. **Generación de la aplicación:** se solicitó construir EduControl con HTML, CSS y JavaScript puro, operaciones CRUD, localStorage, validaciones, datos de demostración y diseño responsive.
3. **Pruebas y refactorización (pendiente de documentar):** registrar los errores encontrados durante las pruebas y las mejoras solicitadas a la IA.
